# 1.6 プロジェクト（Project Profiles）

## 概要

**プロジェクト** は名前付きの設定スナップショットです。プロバイダーの切り替え、MCP サーバーのオン/オフ、Skills のオン/オフ、メモリファイルの切り替えを一つずつ行う代わりに、組み合わせを一度保存しておけばワンクリックで戻せます。

プロジェクトは v3.17.0 で導入され、以下のタブで利用できます：

| アプリタブ | プロジェクトに保存される内容 |
|------------|------------------------------|
| Claude Code | 現在のプロバイダー、有効な MCP サーバー、有効な Skills、現在のプロンプト（メモリファイル `CLAUDE.md`） |
| Codex | 現在のプロバイダー、有効な MCP サーバー、有効な Skills、現在のプロンプト（メモリファイル `AGENTS.md`） |
| Claude Desktop | 現在のプロバイダーのみ（その他の項目は CC Switch が管理していないため） |

その他のアプリではプロジェクト切り替えは表示されません。

## プロジェクト切り替え

対応タブでは、ヘッダーのアプリ切り替えの隣にプロジェクト切り替えが表示されます。そのタブで現在のプロジェクト、または **プロジェクトを使用しない** が表示されます。

クリックすると次の操作ができます：

- プロジェクトを選んで適用する
- **プロジェクトを使用しない** を選んで追跡を止める（現在の設定は変更されません）
- 名前でプロジェクトを検索する
- **新規プロジェクト**：このタブの現在の設定を新しいプロジェクトとして保存する
- **プロジェクトを管理…**：プロジェクトの名前変更や削除

トレイメニューの **プロジェクト** サブメニューにも同じ一覧があり、タブごとにグループ分けされています。

> **設定 → 一般 → ホームページ表示 → プロジェクト切り替えを表示** でヘッダーの切り替えを非表示にできます。非表示にしてもプロジェクトとトレイの **プロジェクト** サブメニューは引き続き使えます。

## プロジェクトは共有、切り替えはタブごと

プロジェクトはグローバルな 1 つのエンティティですが、タブごとに別々のスロットを持ちます：

- **Codex** タブでプロジェクトを適用しても、変わるのは Codex だけです。Claude Code と Claude Desktop は設定もそれぞれの現在のプロジェクトもそのままです。
- あるタブで一度も保存されていないプロジェクトは、管理ダイアログで **このアプリ側は未保存** と表示されます。そのタブで適用すると現在のプロジェクトとして記録されるだけで、設定は変更されません。そのプロジェクトから離れるときに現在の設定が保存されます。

## 切り替え時の自動保存

あるタブでプロジェクト A から B に切り替えると、CC Switch はまずそのタブの現在の設定をプロジェクト A に保存し、その後プロジェクト B を適用します。そのため、プロジェクトには常に最後に離れたときの設定が保存されています。「スナップショットを更新」ボタンがないのはこのためで、プロジェクトが現在の状態のままプロバイダー・MCP・Skills・プロンプトを編集し、別のプロジェクトに切り替えるだけで保存されます。

## プロジェクト適用時の動作

1. そのタブのアプリのプロキシテイクオーバーをオフにします。他にテイクオーバー中のアプリがなければ、ローカルプロキシも停止します。必要であれば適用後にテイクオーバーを再度オンにしてください。
2. 保存されたプロバイダーに切り替えます（カードの **有効化** をクリックしたときと同じ動作）。
3. スナップショットに合わせて MCP サーバーと Skills を有効化・無効化します。差分のみが適用されます。
4. 保存されたプロンプトを有効化します。

適用はベストエフォートです。スナップショットが既に存在しないもの（削除されたプロバイダーやアンインストールされたスキルなど）を参照している場合、その項目はスキップされ、**プロジェクトを適用しました（警告 N 件）** と詳細が表示されます。ロールバックは行われません。

## プロジェクトの管理

**プロジェクトを管理…** を開くと、すべてのプロジェクトが一覧表示されます：

| 操作 | 説明 |
|------|------|
| 名前変更 | プロジェクト名を変更 |
| 削除 | プロジェクトを削除。現在の設定は変更されません |

## 同期とバックアップ

プロジェクトは `~/.cc-switch/cc-switch.db` の `profiles` テーブルに保存されるため、データベースのバックアップ、SQL エクスポート、WebDAV / S3 同期に含まれます。各タブの「現在のプロジェクト」はデバイスごとの情報で、同期のダウンロードで上書きされることはありません。

## ヒント

- クライアントやリポジトリごとにプロジェクトを作成すると便利です。例：「仕事（社内ゲートウェイ）」「個人（自分のキー）」。
- プロジェクトを切り替える前に、実行中の CLI セッションを終了してください。CLI は再起動するまで古い設定を使い続けます。
