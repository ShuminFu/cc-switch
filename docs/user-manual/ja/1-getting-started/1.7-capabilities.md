# 1.7 アプリごとの対応機能

すべての機能がすべてのツールに当てはまるわけではありません。下表は CC Switch がアプリごとに何を管理するかを示します。存在しないボタンを探さずに済むよう参照してください。内容は `src-tauri/src/adapters/` のアダプター機能（`AdapterCapabilities`）、`src-tauri/src/prompt_files.rs` のプロンプト対象、[docs/deeplink-spec.md](../../../deeplink-spec.md)（英語）のディープリンク対応表に基づいています。

| アプリ | プロバイダー | 現在の設定をインポート | MCP | プロンプト（メモリーファイル） | Skills | プロキシのテイクオーバー | プロジェクトが保存する内容 | ディープリンクのインポート |
| --- | --- | :-: | :-: | --- | :-: | :-: | --- | --- |
| Claude Code | 現在のプロバイダーを 1 つ切り替え | ✓ | ✓ | `CLAUDE.md` | ✓ | ✓ | プロバイダー、MCP、Skills、プロンプト | provider、prompt、MCP、skill |
| Claude Desktop | 現在のプロバイダーを 1 つ切り替え | —（Claude Code からインポート） | — | — | — | 代わりにローカルルーティング（[2.6](../2-providers/2.6-claude-desktop.md)） | プロバイダー | — |
| Codex | 現在のプロバイダーを 1 つ切り替え | ✓ | ✓ | `AGENTS.md` | ✓ | ✓ | プロバイダー、MCP、Skills、プロンプト | provider、prompt、MCP |
| Gemini CLI | 現在のプロバイダーを 1 つ切り替え | ✓ | ✓ | `GEMINI.md` | ✓ | ✓ | プロバイダー、MCP、Skills、プロンプト | provider、prompt、MCP |
| Grok Build | 現在のプロバイダーを 1 つ切り替え | ✓ | ✓ | `AGENTS.md` | ✓ | ✓ | プロバイダー、MCP、Skills、プロンプト | provider、prompt、MCP |
| OpenCode | 有効なプロバイダーをすべて同時に読み込む | ✓ | ✓ | `AGENTS.md` | ✓ | — | MCP、Skills、プロンプト | provider、prompt、MCP |
| OpenClaw | 有効なプロバイダーをすべて同時に読み込む | ✓ | — | `AGENTS.md` | — | — | プロンプト | provider、prompt |
| Hermes Agent | 有効なプロバイダーをすべて同時に読み込む | ✓ | ✓ | `AGENTS.md` | ✓ | — | MCP、Skills、プロンプト | provider、prompt、MCP |

補足:

- **プロキシのテイクオーバー**は、ツール自身の設定をローカルプロキシに向けます（フェイルオーバー、使用量統計、プロトコル変換）。テイクオーバー非対応のアプリも、手動でプロキシを指定すれば利用できます。[4.2 アプリのテイクオーバー](../4-proxy/4.2-routing.md) を参照してください。
- **Skills** のディープリンクは常に共有のスキルセットにインストールされます（ディープリンク仕様 §7）。
- 各ツールの設定ファイルの場所は [5.1 設定ファイル](../5-faq/5.1-config-files.md) を参照してください。
