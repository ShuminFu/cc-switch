# 1.7 What Works for Each App

Not every feature applies to every tool. This matrix shows what CC Switch manages per app, so you
do not look for a button that does not exist for the current tab (PRODUCT-33). It reflects the
adapter capabilities in `src-tauri/src/adapters/` (`AdapterCapabilities`), the prompt targets in
`src-tauri/src/prompt_files.rs` and the deep-link app table in
[docs/deeplink-spec.md](../../../deeplink-spec.md).

| App | Providers | Import current config | MCP | Prompts (memory file) | Skills | Proxy takeover | Projects capture | Deep-link import |
| --- | --- | :-: | :-: | --- | :-: | :-: | --- | --- |
| Claude Code | Switch one current provider | ✓ | ✓ | `CLAUDE.md` | ✓ | ✓ | Provider, MCP, Skills, prompt | provider, prompt, MCP, skill |
| Claude Desktop | Switch one current provider | — (imports from Claude Code) | — | — | — | Local routing instead ([2.6](../2-providers/2.6-claude-desktop.md)) | Provider | — |
| Codex | Switch one current provider | ✓ | ✓ | `AGENTS.md` | ✓ | ✓ | Provider, MCP, Skills, prompt | provider, prompt, MCP |
| Gemini CLI | Switch one current provider | ✓ | ✓ | `GEMINI.md` | ✓ | ✓ | Provider, MCP, Skills, prompt | provider, prompt, MCP |
| Grok Build | Switch one current provider | ✓ | ✓ | `AGENTS.md` | ✓ | ✓ | Provider, MCP, Skills, prompt | provider, prompt, MCP |
| OpenCode | All enabled providers are loaded at once | ✓ | ✓ | `AGENTS.md` | ✓ | — | MCP, Skills, prompt | provider, prompt, MCP |
| OpenClaw | All enabled providers are loaded at once | ✓ | — | `AGENTS.md` | — | — | Prompt | provider, prompt |
| Hermes Agent | All enabled providers are loaded at once | ✓ | ✓ | `AGENTS.md` | ✓ | — | MCP, Skills, prompt | provider, prompt, MCP |

Notes:

- **Proxy takeover** points the tool's own config at the local proxy (failover, usage statistics,
  protocol conversion). Apps without takeover can still use the proxy if you point them at it
  manually. See [4.2 App Takeover](../4-proxy/4.2-routing.md).
- **Skills** deep links always install into the shared skills set (see the deep-link spec, §7).
- Per-tool config file locations are listed in [5.1 Configuration Files](../5-faq/5.1-config-files.md).
