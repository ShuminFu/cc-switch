# 1.6 项目（Project Profiles）

## 概述

**项目** 是一份有名字的配置快照。你不必再依次切换供应商、开关 MCP 服务器、开关 Skills、切换记忆文件，只需把这套组合保存一次，之后一键切回。

项目功能在 v3.17.0 引入，支持以下标签页：

| 应用标签页 | 项目保存的内容 |
|------------|----------------|
| Claude Code | 当前供应商、已启用的 MCP 服务器、已启用的 Skills、当前提示词（记忆文件 `CLAUDE.md`） |
| Codex | 当前供应商、已启用的 MCP 服务器、已启用的 Skills、当前提示词（记忆文件 `AGENTS.md`） |
| Claude Desktop | 仅当前供应商（其余维度不由 CC Switch 管理） |

其他应用不显示项目切换器。

## 项目切换器

在支持的标签页上，项目切换器位于顶部栏、应用切换器旁边，显示该标签页当前的项目，或 **不使用项目**。

点击后可以：

- 选择一个项目并应用
- 选择 **不使用项目**，停止跟踪项目（不会改动当前配置）
- 按名称搜索项目
- **新建项目**：把当前标签页的配置保存为新项目
- **管理项目…**：重命名或删除项目

托盘菜单的 **项目** 子菜单提供同样的列表，每个标签页各一个分组。

> 💡 可以在 **设置 → 通用 → 主页面显示 → 显示项目切换** 中隐藏顶部切换器。隐藏后，项目功能和托盘 **项目** 子菜单仍可正常使用。

## 项目全局共享，切换按标签页进行

项目是全局的，但为每个标签页单独保存一个槽位：

- 在 **Codex** 标签页应用项目，只会改动 Codex。Claude Code 与 Claude Desktop 保持原有配置和各自的当前项目。
- 从未在某个标签页保存过的项目，在管理对话框中显示 **本侧未保存**。在该标签页应用它只会把它标记为当前项目，不改动任何配置；离开它时，当前配置会被保存进去。

## 切换时自动保存

在某个标签页从项目 A 切换到项目 B 时，CC Switch 会先把该标签页的当前配置保存回项目 A，再应用项目 B。因此项目总是保存着你上次离开时的配置，这也是为什么没有"更新快照"按钮：在项目为当前时直接修改供应商、MCP、Skills 或提示词，然后切走即可。

## 应用项目时会发生什么

1. 关闭该标签页对应应用的代理接管。如果已没有其他应用处于接管状态，本地代理会被停止。需要时请在之后重新开启接管。
2. 切换到保存的供应商，效果与点击卡片上的 **启用** 相同。
3. 启用或停用 MCP 服务器与 Skills，使其与快照一致，只应用差异部分。
4. 激活保存的提示词。

应用过程尽力而为。如果快照引用的内容已不存在（例如已删除的供应商或已卸载的技能），该项会被跳过，并提示 **项目已应用，N 条警告** 及详情。已完成的部分不会回滚。

## 管理项目

**管理项目…** 打开的对话框列出所有项目：

| 操作 | 说明 |
|------|------|
| 重命名 | 修改项目名称 |
| 删除 | 删除项目，当前配置不会改变 |

## 同步与备份

项目保存在 `~/.cc-switch/cc-switch.db` 的 `profiles` 表中，因此包含在数据库备份、SQL 导出以及 WebDAV / S3 同步中。每个标签页的"当前项目"标记只属于本机，下载同步数据时不会被覆盖。

## 使用建议

- 按客户或代码仓库建立项目，例如"工作（公司网关）"和"个人（自有 Key）"。
- 切换项目前请结束正在运行的 CLI 会话：CLI 在重启前会继续使用旧配置。
