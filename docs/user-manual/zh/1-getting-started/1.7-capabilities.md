# 1.7 各应用支持的功能

并非每个功能都适用于所有工具。下表列出 CC Switch 对每个应用管理哪些内容，避免在当前标签页寻找并不存在的按钮。数据来自 `src-tauri/src/adapters/` 中的适配器能力（`AdapterCapabilities`）、`src-tauri/src/prompt_files.rs` 中的提示词目标，以及 [docs/deeplink-spec.md](../../../deeplink-spec.md)（英文）中的深度链接应用表。

| 应用 | 供应商 | 导入当前配置 | MCP | 提示词（记忆文件） | Skills | 代理接管 | 项目快照包含 | 深度链接导入 |
| --- | --- | :-: | :-: | --- | :-: | :-: | --- | --- |
| Claude Code | 切换一个当前供应商 | ✓ | ✓ | `CLAUDE.md` | ✓ | ✓ | 供应商、MCP、Skills、提示词 | provider、prompt、MCP、skill |
| Claude Desktop | 切换一个当前供应商 | —（从 Claude Code 导入） | — | — | — | 改用本地路由（[2.6](../2-providers/2.6-claude-desktop.md)） | 供应商 | — |
| Codex | 切换一个当前供应商 | ✓ | ✓ | `AGENTS.md` | ✓ | ✓ | 供应商、MCP、Skills、提示词 | provider、prompt、MCP |
| Gemini CLI | 切换一个当前供应商 | ✓ | ✓ | `GEMINI.md` | ✓ | ✓ | 供应商、MCP、Skills、提示词 | provider、prompt、MCP |
| Grok Build | 切换一个当前供应商 | ✓ | ✓ | `AGENTS.md` | ✓ | ✓ | 供应商、MCP、Skills、提示词 | provider、prompt、MCP |
| OpenCode | 同时加载所有已启用的供应商 | ✓ | ✓ | `AGENTS.md` | ✓ | — | MCP、Skills、提示词 | provider、prompt、MCP |
| OpenClaw | 同时加载所有已启用的供应商 | ✓ | — | `AGENTS.md` | — | — | 提示词 | provider、prompt |
| Hermes Agent | 同时加载所有已启用的供应商 | ✓ | ✓ | `AGENTS.md` | ✓ | — | MCP、Skills、提示词 | provider、prompt、MCP |

说明：

- **代理接管**会把工具自己的配置指向本地代理（故障转移、用量统计、协议转换）。不支持接管的应用也可以手动指向代理来使用它。见 [4.2 应用接管](../4-proxy/4.2-routing.md)。
- **Skills** 深度链接总是安装到共享的技能集中（见深度链接规范 §7）。
- 各工具配置文件的位置见 [5.1 配置文件](../5-faq/5.1-config-files.md)。
